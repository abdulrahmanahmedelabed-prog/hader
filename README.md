## حاضر لأوراكل أبكس — نسخة مجانية

أجهزة البصمة والوجه تتصل بقاعدة أوراكل مباشرة عبر ORDS، وتطبيق أبكس يقرأ منها ويكتب إليها ويزامن بينها بإضافات جاهزة. مجانية حتى جهازين، ومفتاح للمزيد. التفاصيل والتثبيت في [`apex/`](apex/).

## Hader for Oracle APEX — free edition

Attendance terminals talking straight to your Oracle database through ORDS, with APEX plug-ins to read, write
and synchronise them. Free for up to 2 terminals; a key for more. See [`apex/`](apex/README.md).
